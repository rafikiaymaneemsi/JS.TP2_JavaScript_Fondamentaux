# TP2 - JavaScript fondamental

## Objectifs

Ce TP introduit les bases de JavaScript : variables et types, opérateurs, comparaisons, structures conditionnelles, `switch`, boucles et simulation de mot de passe.

## Exercices

- Exercice 0 - Initialisation : aucun code source n’était fourni ; aucune solution n’a été inventée.
- Exercice 1 - Variables et types
- Exercice 2 - Opérateurs et comparaisons
- Exercice 3 - Structures conditionnelles
- Exercice 4 - Switch
- Exercice 5 - Boucles
- Exercice 6 - Simulation de mot de passe

## Concepts couverts

Types primitifs, déclarations avec `const` et `let`, opérateurs arithmétiques et logiques, comparaisons, `if/else`, `switch`, boucles `for` et `while`, fonctions, saisie utilisateur et affichage dans le DOM.

## Exécution

1. Ouvrir ce dossier avec VS Code.
2. Lancer `index.html` avec Live Server ou un serveur HTTP local.
3. Choisir un exercice, puis une question. Chaque dossier `exercices/*` possède son propre `index.html` et peut être ouvert directement.

Les solutions et commentaires JavaScript existants ont été conservés. Les scripts sont des modules chargés avec `defer`.
